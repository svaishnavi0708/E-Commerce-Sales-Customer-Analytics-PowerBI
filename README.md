# E-Commerce Sales & Customer Analytics Dashboard

## 📊 Project Overview

The E-Commerce Sales & Customer Analytics Dashboard is an interactive Power BI project developed to analyze e-commerce sales data and generate meaningful business insights.

The dashboard provides a clear view of sales performance, customer behavior, product performance, and key business metrics. It transforms raw data into interactive visualizations that make it easier to understand trends and identify important patterns.

This project was created as part of my Data Analytics learning journey to apply practical skills in data preparation, data modeling, visualization, and business analysis.

---

## 🎯 Project Objective

The main objective of this project is to build an interactive dashboard that helps users:

- Analyze overall sales performance
- Understand customer purchasing patterns
- Identify product performance
- Track important business KPIs
- Analyze sales trends
- Compare different categories and products
- Filter and explore data interactively
- Present complex data in a simple and understandable format

## 📁 Dataset

The project uses an e-commerce sales dataset containing information related to:

- Customers
- Products
- Sales transactions
- Product categories

The data was prepared and structured before creating the Power BI data model.

---

## 🧩 Data Model

The Power BI model was designed using a structured data model with dimension and fact tables.

### Dimension Tables

- DIM_CUSTOMER
- DIM_PRODUCT
- DIM_DATE

### Fact Table

- FACT_SALES

Relationships were created between the tables to support accurate analysis and interactive filtering.
